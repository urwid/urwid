class urwid.AttrWrap(w: WrappedWidget, attr: Hashable | Mapping[Hashable, Hashable], focus_attr: Hashable | Mapping[Hashable, Hashable] = None)¶

A special case of the AttrMap widget.

Passes all function calls and variable references on to the wrapped widget.

Deprecated since version 0.9.9: Maintained for backwards compatibility only, new code should use AttrMap instead. This API will be removed in version 7.0.

Build the widget from an existing widget and attribute mapping.

Parameters:

  • w – widget to wrap (stored as self.original_widget)

  • attr – attribute to apply to w

  • focus_attr – attribute to apply when in focus, if None use attr

Deprecated since version 0.9.9: Maintained for backwards compatibility only, new code should use AttrMap instead. This API will be removed in version 7.0.

>>> from urwid import Divider, Edit, Text
>>> AttrWrap(Divider("!"), "bright")
<AttrWrap flow widget <Divider flow widget '!'> attr='bright'>
>>> AttrWrap(Edit(), "notfocus", "focus")
<AttrWrap selectable flow widget <Edit selectable flow widget '' edit_pos=0> attr='notfocus' focus_attr='focus'>
>>> size = (5,)
>>> aw = AttrWrap(Text("hi"), "greeting", "fgreet")
>>> next(aw.render(size, focus=False).content())
[('greeting', None, ...'hi   ')]
>>> next(aw.render(size, focus=True).content())
[('fgreet', None, ...'hi   ')]

get_attr() → Hashable¶

Return the attribute applied to the wrapped widget.

get_focus_attr() → Hashable | None¶

Return the attribute applied to the wrapped widget when it is in focus.

set_attr(attr: Hashable) → None¶

Set the attribute to apply to the wrapped widget.

>> w = AttrWrap(Divider(“-“), None) >> w.set_attr(‘new_attr’) >> w <AttrWrap flow widget <Divider flow widget ‘-’> attr=’new_attr’>

set_focus_attr(focus_attr: Hashable) → None¶

Set the attribute to apply to the wrapped widget when it is in focus.

If None this widget will use the attr instead (no change when in focus).

>> w = AttrWrap(Divider(“-“), ‘old’) >> w.set_focus_attr(‘new_attr’) >> w <AttrWrap flow widget <Divider flow widget ‘-’> attr=’old’ focus_attr=’new_attr’> >> w.set_focus_attr(None) >> w <AttrWrap flow widget <Divider flow widget ‘-’> attr=’old’>

Return the sizing modes supported by the wrapped widget.

urwid.MetaSuper¶

Alias of type, kept so that class definitions naming it keep importing. Drop it from metaclass= arguments and from base lists; while it is still listed as a base, it has to be the last one. The name will be removed in version 7.0.

Deprecated Import Paths¶

Deprecated since version 2.4.0: The display modules moved into the urwid.display package. The old names will be removed in version 7.0.

Deprecated Extension Points¶

Deprecated since version 4.0.10: Overriding get_data() in a BarGraph subclass, or assigning get_data on an instance. Call BarGraph.set_data() instead. Support will be removed in version 7.0.

Deprecated since version 5.0: Defining get_input_nonblocking() in a subclass of display.raw.Screen. Override get_available_raw_input() instead. Support will be removed in version 7.0.
