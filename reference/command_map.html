Command Map¶

class urwid.CommandMap¶

dict-like object for looking up commands from keystrokes.

Default values:

tab, ctrl n

'next selectable'

shift tab, ctrl p

'prev selectable'

ctrl l

'redraw screen'

esc

'menu'

up, down, left, right

'cursor up', 'cursor down', 'cursor left', 'cursor right'

page up, page down

'cursor page up', 'cursor page down'

home, end

'cursor max left', 'cursor max right'

space, enter

'activate'

Only containers created with select_navigation=True handle 'next selectable' and 'prev selectable', see Moving the Focus with Tab.

Edit also handles these readline-style commands, which no key is mapped to by default: 'cursor word left', 'cursor word right', 'delete word left', 'delete word right', 'delete to start of line' and 'delete to end of line'. A word is a run of letters, digits and underscores, and a line ends at a newline.

  • 'delete word left' stops at punctuation, as readline’s backward-kill-word (meta backspace) does, except that an underscore is part of a word here. It is not bash’s ctrl w (unix-word-rubout), which deletes back to the previous whitespace.

  • 'delete to start of line' and 'delete to end of line' work on lines that end at a newline. 'cursor max left' and 'cursor max right' move to the edge of the screen row instead, so on a wrapped line they stop earlier than the deletes reach.

>>> cm = CommandMap()
>>> cm.bind(Command.WORD_LEFT, "meta b")
>>> cm.bind(Command.DELETE_TO_LINE_START, "ctrl u")

Initialize the command map with the class’s default key-to-command bindings.

bind(command: str | Command, *keys: str) → None¶

Bind keys to command, refusing a key that is already bound to a different command.

A key already bound to command is accepted. Item assignment (command_map[key] = command) remains the way to rebind a key on purpose.

>>> cm = CommandMap()
>>> cm.bind("quit", "q", "ctrl c")
>>> cm.bind("quit", "ctrl l")
Traceback (most recent call last):
...
ValueError: Key 'ctrl l' is already bound to 'redraw screen', cannot also bind it to 'quit'
Parameters:

  • command – the command to bind.

  • keys – keystrokes to bind to command, added to those it already has.

Raises:

ValueError – a key in keys is already bound to a different command; the command map is left unchanged.

clear_command(command: str | Command) → None¶

Remove every keystroke currently mapped to command.

copy() → Self¶

Return a new copy of this CommandMap, likely so we can modify it separate from a shared one.

restore_defaults() → None¶

Reset the command map to the class’s default key-to-command bindings.
