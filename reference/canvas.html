set_pop_up(w: AbstractWidget, left: PopUpLeft, top: PopUpTop, overlay_width: PopUpSize, overlay_height: PopUpSize, *, anchor_height: int | None = None, anchor_width: int | None = None, anchor_side: Literal['left', 'right'] = 'left', on_anchor_side: Callable[[Literal['left', 'right']], None] | None = None, on_unhandled_key: Callable[[str], str | None] | None = None, pass_key_below: PopUpPassKey | None = None, on_click_outside: Callable[[], None] | None = None, margin: tuple[int, int] | None = None) → None¶

Add pop-up information to the canvas.

This information is intercepted by a PopUpTarget widget higher in the chain to display a pop-up at the given (left, top) position relative to the current canvas.

A negative position opens the pop-up to the left of or above this canvas, for example over a launcher with the current item on the launcher’s row. A pop-up that would extend past an edge of the PopUpTarget is moved, and shrunk when it is larger, to fit inside it.

An alignment instead of a number places the pop-up inside the whole PopUpTarget, wherever this canvas is: left="center", top="middle" centres a dialog on the screen. It is applied after the size is known, so it also centres a "pack" sized pop-up.

Parameters:

  • w – widget to use for the pop-up

  • left – x position for left edge of pop-up, may be negative, or "left", "center" or "right" to align the pop-up inside the target

  • top – y position for top edge of pop-up, may be negative, or "top", "middle" or "bottom" to align the pop-up inside the target

  • overlay_width – width of overlay in screen columns > 0, ("relative", percentage) of the columns from the pop-up’s left edge to the right edge of the PopUpTarget (of all its columns when left is an alignment), with a percentage > 0, or "pack" for the width of w as a fixed widget

  • overlay_height – height of overlay in screen rows > 0, ("relative", percentage) of the rows from the pop-up’s top edge to the bottom edge of the PopUpTarget (of all its rows when top is an alignment), with a percentage > 0, or "pack" for the rows of w as a flow widget at the pop-up width

  • anchor_height – rows of the launcher directly above the pop-up, >= 0, or None to place the pop-up exactly as given. With an anchor, PopUpTarget keeps the pop-up off those rows: it goes below them when it fits there, above them when it fits there, and otherwise on the side with more rows, with its height clipped to that side. It needs top as a number of rows.

  • anchor_width – columns of the anchor beside the pop-up, >= 0, such as a launcher or the menu that opened the pop-up, or None to place the pop-up exactly as given. With an anchor, PopUpTarget keeps the pop-up off those columns, by the same rule as for anchor_height, with the side anchor_side gives preferred. It needs left as a number of columns: the column of the anchor edge that the pop-up touches on its preferred side. A relative overlay_width is then a percentage of the columns on the preferred side.

  • anchor_side – the side of the pop-up the anchor is on. "left": the anchor is the anchor_width columns before left, and the pop-up prefers to start at left, to the right of the anchor. "right": the anchor is the anchor_width columns from left on, and the pop-up prefers to end just before left, to the left of the anchor. It needs anchor_width.

  • on_anchor_side – called by PopUpTarget each time it places the pop-up, with the side of the pop-up the anchor ended up on, in the terms of anchor_side. It differs from anchor_side when the pop-up moved to the other side of the anchor. A widget that opens a chain of pop-ups, such as submenus, uses it to know which way leads back. It needs anchor_width.

  • on_unhandled_key – called by PopUpTarget with a key that w returned unhandled while it is the topmost open pop-up; it returns None when it handled the key, or the key to pass on. None passes every unhandled key on.

  • pass_key_below – called by PopUpTarget with a key that w and on_unhandled_key left unhandled while w is the topmost open pop-up, and with a function that sends a key to the widgets w is drawn over. That function returns the key when those widgets leave it unhandled, and None when they handled it. The callback returns the key to pass on, or None when the key was handled. It belongs to the pop-up that was topmost when the key arrived, so it can run after that pop-up closed during the same keypress. None passes every such key on without offering it to the widgets under the pop-up.

  • on_click_outside – called by PopUpTarget instead of passing on a press of mouse button 1, 2 or 3 outside w while it is the topmost open pop-up. None leaves such a press unhandled.

  • margin – (columns, rows) of the PopUpTarget kept clear at each of its edges, each >= 0, or None for no margin. The pop-up is at most as large as the target without the margins, whatever its size was given as. An alignment places it inside the margins, and a relative size on an aligned axis is a percentage of the cells inside them. A pop-up placed by a number is not moved; it is shifted only to fit inside the target. A margin that would leave no cell inside is reduced until at least one cell is left.

Raises:

CanvasError – the canvas is already finalised, the anchor height or width is negative, an anchor height is given with an aligned top, an anchor width with an aligned left, anchor_side is neither "left" nor "right", anchor_side="right" or on_anchor_side is given without an anchor width, a position is neither a number nor an alignment of its axis, an overlay dimension is not a positive integer, a positive finite percentage or "pack", or margin is not a pair of integers >= 0

class urwid.TextCanvas(text: list[bytes] | None = None, attr: list[list[tuple[Hashable, int]]] | None = None, cs: list[list[tuple[Literal['0', 'U'] | None, int]]] | None = None, cursor: tuple[int, int] | None = None, maxcol: int | None = None, check_width: bool = True)¶

class for storing rendered text and attributes.

Build a text canvas from the given lines and attributes.

Each line of text is padded with spaces to maxcol columns. attr and cs hold one list of runs per line. A run is a (value, length) tuple that applies value to the next length bytes of the line. The runs of a line cover it from its first byte, and their lengths add up to at most the padded line’s length. The bytes after the last run, and every line with no list of runs, get None: the default attribute, or the default character set.

For example, attr=[[("bold", 3), ("red", 2)], [("blue", 4)]] with text=[b"foobar", b"test string"] shows foo as bold, ba as red, r with the default attribute, test as blue, and the rest of the second line with the default attribute:

>>> canvas = TextCanvas([b"foobar", b"test string"], [[("bold", 3), ("red", 2)], [("blue", 4)]])
>>> [[(a, text) for a, _cs, text in row] for row in canvas.content()]
[[('bold', b'foo'), ('red', b'ba'), (None, b'r     ')], [('blue', b'test'), (None, b' string')]]
Parameters:

  • text – lines of text, encoded in the screen’s encoding (see urwid.set_encoding())

  • attr – runs of display attributes for each line: palette entry names, AttrSpec or LayeredAttr values, or None for the default attribute

  • cs –

    runs of character sets for each line:

    • "0": the DEC special graphics set, in a non-UTF-8 encoding.

    • "U": bytes written unchanged, without filtering control characters; in a non-UTF-8 encoding, also the IBM PC character set.

    • None: the default set.

  • cursor – (x,y) of cursor or None

  • maxcol – screen columns taken by this canvas

  • check_width – check and fix width of all lines in text

Raises:

  • CanvasError – a line of text is not a plain string in the screen encoding, is wider than maxcol, or has an attribute or character set run extending beyond its padded text.

  • TypeError – maxcol is not an integer.

parse_osc(buf: bytes) → None¶

Parse operating system command: a window title, or an OSC 8 hyperlink for the text written after it.

The OSC bodies are recognised by urwid.ansi_parser.resolve_osc_title() and urwid.ansi_parser.resolve_osc_hyperlink(), shared with ANSIText. An invalid OSC 8 command ends the current link, so the text after it does not point at the previous target; An over-long one, which never reaches this method, ends it as well. The body is in the encoding addbyte() passes characters on in, and as in tmux, a title that is not valid in it is not set. A string that had a sequence that is not valid UTF-8, in UTF-8 mode, sets no title and ends the current link.

Parameters:

buf – the OSC command body, excluding the ESC ] framing and terminator.

CanvasCache¶

class urwid.CanvasCache¶

Cache for rendered canvases.

Automatically populated and accessed by Widget render() MetaClass magic, cleared by Widget._invalidate().

Stores weakrefs to the canvas objects, so an external class must maintain a reference for this cache to be effective. At present the Screen classes store the last topmost canvas after redrawing the screen, keeping the canvases from being garbage collected.

_widgets[widget] = {(wcls, size, focus): weakref.ref(canvas), …} _refs[weakref.ref(canvas)] = (widget, wcls, size, focus) _deps[widget] = {dependent_widget, …} _children[dependent_widget] = {widget, …}

_children is the reverse of _deps. It removes a dependent widget from _deps once that widget has no cached canvas left. Widgets are not guaranteed to be weak-referenceable, so neither index can use weak references.
